💡 Smart Street Light

An IoT-based Smart Street Light project focused on real-time monitoring and detection of electrical faults in street-light systems. The project uses sensor-based monitoring to identify conditions such as open-circuit and overload faults while tracking voltage and current parameters. It provides real-time location monitoring of street-light units, while fault and operating data are transmitted to the cloud and simultaneously updated on a web interface. It demonstrates the application of IoT, sensor technologies and location-based monitoring for smart infrastructure, fault detection and efficient maintenance.
